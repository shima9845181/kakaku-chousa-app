# 価格調査ソフト

さかえ電気の社内ツール。仕入価格・市場価格の検索と簡易集計（見積依頼書・見積ソフト連携・資料検索・ネット価格DB）。

- 公開版（スマホ・タブレット用）: https://shima9845181.github.io/kakaku-chousa-app/
- PC版は同じ `価格調査ソフト.html` を `file://` で開く（見積ソフトの歩掛りマスタを読み取り専用で直読）。

## データについて

- データはブラウザ内（IndexedDB）にのみ保存され、GitHub には**コードだけ**が公開される。
- 端末間の受け渡しは、設定タブの「全データを書き出し（JSON）」→「バックアップから復元」で行う（写真管理アプリと同方式）。
- `自動保存/` `_backup/` `*.json` は `.gitignore` で除外（データを誤って公開しない）。

## 更新の反映

フォルダの `deploy.bat` をダブルクリック（git add / commit / push）。数分で公開版に反映される。
